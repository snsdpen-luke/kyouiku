# Classroom への自動投稿の受け口（Apps Script）

AI（crocky）が教材を push して公開したあと、そのリンクを Classroom のクラスに「資料」として載せるためのもの。
**既定は下書き。** 生徒に出すのは、剛さんが Classroom で下書きを開いて「投稿」を押したとき。

```
crocky（この Mac）──classroom.mjs──▶ Apps Script（剛さんのアカウントで動く）──▶ Classroom（下書き）
                合言葉つき                    kyouiku の教材の URL だけ受け付ける
```

## 準備（剛さんが1回だけ。学校の Google アカウントで。10分ほど）

1. <https://script.google.com/> で「新しいプロジェクト」。名前は自由（例：Classroom 投稿）
2. 最初からある `コード.gs` の中身を全部消し、`Classroom投稿.gs` の中身を貼って保存する
3. 左の「サービス」の ＋ → **Google Classroom API** を選んで「追加」
4. 上の関数の選択で `setup` を選び「実行」。権限の確認が出たら許可する（「Classroom のクラスを表示」「資料を作成」など）
   - 「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」。自分で作ったスクリプトなので問題ない
   - **ここで止められる（管理者がブロック）なら、学校の設定で Classroom API が使えない。** そのときは AI に知らせる（この仕組みは使えない）
5. 下の「実行ログ」に `合言葉（KEY）: ……` と `受け持っているクラス: 数` が出る。合言葉を控える
6. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（わからないところアンケートと同じ。合言葉がないと何もできない）
7. 出てきた **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）を控える
8. **Mac のターミナルで**（会話には合言葉を貼らない）：
   ```bash
   cd ~/dev/kyouiku && node .claude/skills/koukai/classroom.mjs setup 'ウェブアプリのURL' '合言葉'
   ```
   `ok 受け口につながった` と出れば完了。設定はこの Mac の `~/.config/kyouiku/classroom.json` にだけ置かれる（GitHub には上がらない）
9. あとは AI に「Classroom のクラスに呼び名を付けて」と言えば、一覧を出して**科目ごと**に呼び名を付ける（例：電気回路・電子計測制御・コンピュータシステム技術）。同じ科目のクラスが2つ以上あれば、1つの呼び名にまとめる（載せると全部に入る）

## クラスが増えた・終わったとき

- **増えた**：Classroom でクラスを作り、AI に「〇〇のクラスが増えた」と言う。AI が一覧から見つけて呼び名に足す（`classroom.mjs map 呼び名 新しいid`）。Apps Script はそのままでよい
- **年度が終わった**：Classroom でアーカイブすると一覧から消える。AI が `courses` で気づいて呼び名から外す（`unmap`）
- **別の先生のクラス**：載せられない（受け口は剛さんが先生として受け持つクラスだけを見る）

職場の Mac でも使うなら、8 をそちらでもやる。

## AI がいつ載せるか

- **新しい教材を公開したとき**：その科目のクラスに下書きで載せる（呼び名が決まっていれば聞かない。決まっていなければ聞く）
- **剛さんが「Classroom に出して」と言ったとき**：言われたクラスに載せる。「すぐ公開して」と言われたときだけ下書きでなく生徒に出す
- **直しただけのとき**：載せない（URL は同じなので、生徒は前のリンクから新しい版を開く）
- 同じ URL がもうそのクラスにあれば、二重に載せない（下書きも見る）

## 気をつけること

- **合言葉が漏れたら**：Apps Script で `resetKey` を実行し、8 をやり直す。漏れても、載せられるのは kyouiku の教材の URL だけ（ほかのサイトは受け付けない）で、下書きにしかならない
- 受け口が見るのは「受け持っているクラスの一覧」と「資料を作る」だけ。生徒の名前・成績・提出物には触れない
- 投稿をやめるときは「デプロイ」→「デプロイを管理」→ アーカイブ。AI 側は「つながらない」と出して止まる
- Classroom API で作った資料は、同じ Apps Script からしか直せない。手で消すのは Classroom の画面から普通にできる
