# 電子計測制御 小テスト第2回の受け口（Google スプレッドシート）

制御クイズ100（`/seigyo100/`）のメニューの「小テスト第2回」は、提出した答案をこのスプレッドシートに送る。
記述8問（34点）は先生が読んで採点する。図と計算（16点）はアプリが採点した点が入る。

送り先 `T2_URL`（`制御クイズ100.html`）が空のあいだは、どこにも送らない（ダミーの提出）。

## 準備（先生が1回だけ。学校の Google アカウントで）

1. Google ドライブで新しいスプレッドシートを作る（名前は自由。例：電子計測制御 小テスト第2回）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初からある `コード.gs` の中身を全部消し、`小テスト第2回.gs` の中身を貼って保存する
4. 上の関数の選択で `setup` を選び「実行」。権限の確認が出たら許可する。スプレッドシートに「答案」のシートができる
5. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
6. 「デプロイ」を押して出てくる **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）を控える
7. その URL をブラウザで開き、`{"ok":true,"msg":"電子計測制御 小テスト第2回の受け口です"}` と出れば動いている
8. URL を AI（crocky）に渡す。`制御クイズ100.html` の `const T2_URL=''` に入れる

## 「答案」シートの列

| 列 | 中身 |
|---|---|
| A〜E | 受付日時・出席番号・提出ID・デモ（先生用デモ `#demo` から送ったもの）・図と計算の点（16点） |
| F〜R | 第1問〜第13問の答え（第1問は ①〜④ を「／」でつないだもの） |
| S | ヒントを見た計算の問題の番号 |
| T〜AA | 記述8問の点（空。先生が入れる。列の見出しに満点） |
| AB | 合計（記述の点が全部入ると出る） |

採点の観点と模範解答は、アプリの提出後の画面（`#demo` で受けると見られる）と、`制御クイズ100.html` の `T2` にある。

## 気をつけること

- **「アクセスできるユーザー：全員」が選べない学校がある。** 選べないときは AI に相談する
- 受け口の URL は公開ページに載るので、だれでも送れてしまう。形のおかしいもの（4けたでない出席番号・答えの数がちがう など）は捨てるが、いたずらの答案そのものは防げない。おかしな行は消す
- 同じ提出IDは1行にしかならない（通信が切れて送り直しても二重にならない）。同じ出席番号が2行あるときは、受付日時を見る（端末を変えて受け直した、など）
- 先生用デモで送った行は D 列に「デモ」と入る。採点の前に消す
- 受付をやめるときは「デプロイ」→「デプロイを管理」→ アーカイブ。アプリは「送れませんでした」と出し、答えは端末に残る
- 問題の並び・点は、アプリの `T2` と `.gs` の `Q` で同じにする（`node regression-seigyo100.js 制御クイズ100.html` が突き合わせる）
