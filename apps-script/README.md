# わからないところアンケートの受け口（Google スプレッドシート）

ふりかえり演習（`/review1/`）の「わからないところアンケート」は、答えをこのスプレッドシートに直接送る。
無記名で、届くのは「回答ID（端末で作るでたらめな文字）・選んだ項目の番号・ほかにわからないこと」だけ。

## 準備（先生が1回だけ。学校の Google アカウントで）

1. Google ドライブで新しいスプレッドシートを作る（名前は自由。例：わからないところアンケート）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初からある `コード.gs` の中身を全部消し、`わからないアンケート.gs` の中身を貼って保存する
4. 上の関数の選択で `setup` を選び「実行」。権限の確認が出たら許可する。スプレッドシートに「回答」と「集計」のシートができる
5. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
6. 「デプロイ」を押して出てくる **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）を控える
7. その URL をブラウザで開き、`{"ok":true,"msg":"わからないところアンケートの受け口です"}` と出れば動いている
8. URL を AI（crocky）に渡す。`ふりかえり演習.html` の `const ASK_URL=''` に入れると、メニューに「わからないところアンケート」が出る

## 気をつけること

- **「アクセスできるユーザー：全員」が選べない学校がある。** 学校のドメインだけに絞ると、アプリからは送れない（ブラウザが学校のログイン情報を付けないため）。選べないときは AI に相談する
- 受け口の URL は公開ページに載るので、だれでも送れてしまう。形のおかしいもの（知らない項目番号・長すぎる文）は捨てるが、いたずらの回答そのものは防げない。おかしな行は「回答」シートから消せば「集計」も変わる
- 受付をやめるときは「デプロイ」→「デプロイを管理」→ アーカイブ。アプリは「送れませんでした」と出す
- クラスごとに分けたいときは、「受付日時」で区切る（授業の時間で分かれる）
- 項目の番号は、スプレッドシートの列と対応している。アプリの `ASK` と `.gs` の `ITEMS` は同じ並びにし、番号を変えない。足すときは両方の最後に足し、`setup` をやり直す（回答が入っていると止まる）

## 送る中身（アプリ → 受け口）

`POST`（本文は JSON、ヘッダは付けない）

```json
{"rid":"3f9a0c1d2e4b5a6978c0d1e2","items":[3,14,22],"memo":"ACK のところ","v":1}
```

返事は `{"ok":true}`。同じ `rid` をもう一度送っても行は増えない（`{"ok":true,"dup":true}`）。
