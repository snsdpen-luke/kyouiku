単線図（タップで大きく）
施工条件

    部品図 タップして、図の置きたい所をタップ

    描き方
    1. 単線図を見て、要る部品を部品図から選び、図の置きたい所をタップ。記号（イ・ロ…、ボックスは B1・B2…）を単線図と同じにする
    2. 単線図どおりに置けると、部品のあいだにケーブル（薄い帯）が出る
    3. 線の色を選び、端子（○）からボックス（点線の円）までドラッグ（または 端子 → ボックス とタップ）。ボックスの中に接続点（●）ができる。同じ●につなぐ線は、端子からその●へ
    4. ●をボックスの外まで引っぱり出すと、●から線を伸ばせる（器具の端子や、ほかのボックスへ）。ボックスの中で動かすと●が動く
    5. 線をタップ → 色を変える・つなぎ先を変える・消す。線の真ん中の青い丸をドラッグすると、線が曲がる。●をタップ → 動かす・まとめる・消す
    6. 部品・ボックス・●はドラッグで動かせる。部品をタップすると記号を変えたり消したりできる
    7. W と N は白い線、B と L は黒い線をつなぐ端子
    8. 間違えたら「↶ 1つ戻す」（Ctrl+Z）で、1つ前の図に戻る
    9. 図が小さいときは、図の右下の「＋」で拡大し、「✋ 移動」で見る所を動かす。「全体」で元に戻る
