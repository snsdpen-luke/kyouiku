# naoshi — すでにある教材を直す

剛さんがこれまで何度も言い直してきたのは、だいたい次の3つです。このスキルはそれを先回りします。
1. **直したのに画面が変わっていない**（build.py を忘れた・版を上げていない・別の所を直した）
2. **画面に収まっていない**（横長の Chromebook・4:3 で縦に動かす、文字が2行に折れる、ボタンが押しにくい）
3. **どう見ればいいか分からない**（プレビューの場所・URL を言っていない）

## 1. 直す前に

1. 本体を特定する。直すのは日本語名の `.html` だけ。`<フォルダ>/index.html` は生成物（直そうとするとフックが止める）。対応は `build.py` の表 `PAGES`
2. その教材の `HANDOFF*.md` があれば読む（ラダー工房 `HANDOFF.md`・進路 `HANDOFF-進路シミュレーション.md`・ミニマート・技能筆記・複線図・馬レース・Arduino `arduino/HANDOFF.md`）。禁止事項はそちらが正しい
3. 剛さんの言葉が**前の指示を取り消す**ものか確かめる（例：「1回じゃなくて3回のままで」「減らさないで元に戻して」）。取り消しなら、前の直しを戻す範囲を先に言う
4. 指示があいまいでも、直し方が2通り以上あって**生徒の学ぶ中身が変わる**ときだけ聞く。見た目や配置は既定（2章）で進めて報告に書く

## 2. 聞かずに守る既定（剛さんが何度も言ったこと）

| 場面 | 既定 |
|---|---|
| 画面の大きさ | 横向きの Chromebook（1366×768）と 4:3 で、**1ページが縦に動かさずに収まる**。収まらなければ余白・文字の行間・図を詰める。ページを増やして逃げない |
| 文字 | ボタンや見出しの文字が**2行に折れない**（折れるなら短い言葉にするか小さくする）。14px 以上。読みにくいと言われたら、太さと色の差を先に上げる（Web フォントは使わない） |
| 色 | 白基調・ライトモード固定。グラデーションより単色。強いほど赤・弱いほど青 |
| 操作 | タップ前提。押せる物は 44px 以上。ドラッグだけの操作を作らない（−／＋ボタンかキーを付ける）。バーやつまみは**太く**、数字を押すと元に戻る |
| 意味の分からない部品 | 剛さんが「これ何？」と言ったボタンは、説明を足すより**消すか名前を変える**ほうを先に考える |
| 先生用 | 「何度もやり直せる先生用」は、URL の末尾 `#sensei`（既存の教材で `#demo` を使っている物はそれに合わせる）。保存の箱を生徒と分ける |
| 名前を変える | 画面の題・`<title>`・README の3つの表・`build.py` の `PAGES` のメモを全部変える。**URL（フォルダ名）は変えない**（配ったリンクが切れる）。変えたいと言われたら、切れることを言ってから |
| 文章 | です・ます調の普通の説明文。キャラクターの口調にしない |

## 3. 直したあと（毎回・全部）

```bash
# 1) 版を上げる：本体の VER を今日の日付＋英字（2026-11-14a → b → c …）
# 2) 配る場所へ写す
python3 build.py
# 3) 機械で確かめる（build 忘れ・VER の上げ忘れ・確認スクリプト・confirm や外のフォントが増えていないか）
python3 kakunin.py
```
- `kakunin.py` が NG を出したら、直してからもう一度。**NG のまま報告しない**
- 新しく足した動きは、その教材の `regression-<フォルダ>.js` に項目を1つ足す（ない教材は無理に作らない。ただし同じ所を2回直したら作る）
- 画面を変えたら、実物の Chrome で見る：
  ```bash
  node .claude/skills/kyouzai/check-browser.mjs 本体.html --walk none --only chromebook,4x3 --out /tmp/naoshi/<フォルダ>
  ```
  `report.md` の NG（縦に動かす・はみ出し・重なり・小さい文字）をなくし、**画面写真を自分の目で見る**。直したところが写っている写真を選んで剛さんに見せる（Read で開く or SendUserFile）。`--walk next` なら「次へ」を押しながら全ページ撮る

## 4. 剛さんに見せる（「見せて」「どうやって見るの」と言われる前に）

報告の最後に、必ずどれか1つを書く。
- **まだ push していない**：ブラウザの画面（Claude の Browser pane）で `file:///Users/uemuratsuyoshi/dev/kyouiku/<本体>.html` を開いて見せる。4:3 を見たいと言われたら `resize_window` で 1024×768
- **push した**：生徒に配る URL（`https://snsdpen-luke.github.io/kyouiku/<フォルダ>/`）と、表示されるはずの版。公開まで1〜2分かかることも書く（確かめ方は koukai）
- 先生用があるなら、その入口（`#sensei` / `#demo` / `N` キー）も

## 5. 報告（3〜5行）

何を直したか（剛さんの言葉に対応させて）／聞かずに既定で決めたこと／`kakunin.py` と確認スクリプトの結果／どう見るか（4章）／push したか、していないか。

push は剛さんが「push して」「公開して」と言ったときだけ（→ koukai）。Trinity から任された作業（worktree の中）なら push しない。
