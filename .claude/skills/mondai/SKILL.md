# mondai — 問題と小テスト

剛さんが毎回言い直してきたこと（出席番号・1回だけ・ダミー提出・先生用デモ・30分・迷わせる選択肢・範囲）を、**最初から既定で入れる**ためのスキル。

## 1. 最初に確かめる表（足りない所は既定で進め、報告に書く）

| 項目 | 聞かずに決めてよい既定 | 剛さんが前に言ったこと |
|---|---|---|
| 出題の範囲 | 授業で扱った教材・記録にある用語だけ。範囲の外の語は問題にも選択肢にも使わない | 「PLC やフィードバック制御は出さない」→ 後で「フィードバック制御は使ってよい」。**範囲は変わる**。決めた範囲は確認スクリプトの禁止語の表に書く |
| 科目の芯 | 科目名の中心から出す（電子計測制御なら「計測と制御」。題材の車だけにしない） | 「車の分野みたいになってる。計測と制御をメインに」 |
| 問題の数 | 練習は分野ごとに同じ数。小テストは**30分で解ける数**（目安：語群・選択で 1問 40〜60 秒） | 30問・50問・20問と回ごとに違う。数を言われたら従う。「減らさないで元に戻して」もあった |
| 選択肢 | 5択。**まちがいの選択肢は、生徒が本当に迷うもの**。明らかに違う物を入れない。正解と同じくらいの長さ | 「うわ、どれが正しいんだろうって悩む選択群に」 |
| 問い方 | 用語→意味だけにしない。**意味→用語**・使いどころ・大事な場面・数を求めるを混ぜる | 「意味から逆に用語を考える問題も」 |
| 記述 | 採点しやすい物だけ（指定語句を入れて書く）。「気をつけることを説明せよ」のような観点がぼやける物は作らない | 「採点がむずかしい」「この記述はいらない」 |
| 図 | 図がないと答えられない問いには図を付ける（SVG をファイルの中に描く） | 「図示する必要がある」 |
| 小テストの出席番号 | 4けたの数字（`/^\d{4}$/`）を最初に入れる | 「出席番号は4けたで」。**ただし「不要」と言われた教材もある**。生徒だけで使う練習なら入れない |
| 小テストの回数 | **1回だけ**。提出したら受け直せない | 「2回目は受けられないように」「提出は１回限定で」 |
| 提出 | **ダミー**：どこにも送らず「送信しています…」のあと「提出しました」と受付時刻。提出後に点数と答え合わせ | 第1回から変わらない。本当に送るのは剛さんが決めたときだけ |
| 制限時間 | あり。**締め切り時刻**で持つ（開き直しても時間は戻らない） | 「緊張感を持たせる」 |
| 先生用デモ | URL の末尾 `#sensei`（既存の教材で `#demo` なら合わせる。`/^#(demo|teacher|sensei)$/` で両方受ける）：何度でも受け直せる・ステージをとばせる・保存の箱を生徒と分ける | 「教師用のなんどもやり直せるデモモード」を**2回**頼まれた。最初から付ける |
| ランク・称号 | 付けない（A ランク・D ランクなど） | 「ランク機能はいらない」 |
| 「先生に見せてください」 | 生徒だけで解く物には出さない | 「完全生徒用なので先生に見せる機能は不要」 |
| ゲーム感 | ステージ制・残り時間・ステージごとの結果で「クリア感」を出す（ランクは出さない） | 「ゲームクリア感覚で」 |
| 計算問題 | その問題に特化した電卓と、1段のヒントを付ける | 小テスト第2回で頼まれた |

## 2. 作る順

1. **範囲を書き出す**：読む物（`~/dev/all-db/projects/kyouiku/jugyou/` の授業記録・その単元の教材）と、出す用語・出さない用語の一覧。剛さんが範囲を言っていればそれが正
2. **問題を作る**：データは1か所（配列）に。1つ選ぶ問題は**正解を先頭に書き、画面で位置を配り直す**。数の答えはモデルや式から計算して書く（手で書かない）
3. **査定用の一覧を出す**（剛さんは問題を自分の目で査定する）：
   ```
   node .claude/skills/mondai/ichiran.mjs 本体.html <問題の配列の名前> > /tmp/mondai-ichiran.md
   ```
   `ichiran.mjs` は jsdom で本体を開き、配列を番号・分野・問題文・選択肢（正解に ◎）・解説の表にする。これを剛さんに渡し、消す・直す番号をもらう。**生徒の答えや成績は入れない**
4. **確認スクリプトに点検を足す**（`regression-<フォルダ>.js`。手本は `regression-seigyo100.js`）：
   - 数：全体の問題数・分野ごとの数・問い方ごとの数
   - 重複：問題文・正解の文・同じ問題の中の選択肢
   - 偏り：正解の位置（同じ数ずつ・同じ位置が3回続かない）、**正解だけが一番長い問題が多すぎない**
   - 範囲：出さない語の正規表現（決めた日付と剛さんの言葉をコメントに）
   - 解説：空でない・長すぎない・です・ます
5. **小テストを通しで確かめる**（jsdom）：出席番号の4けた以外を断る／制限時間が締め切り時刻で動く／未回答の確認／ダミー提出のあと受け直せない／再読み込みしても受け直せない／`#sensei` では何度でも受けられて生徒の記録に混ざらない／`confirm` を `() => false` にしても最後まで行ける
6. 直したあとの手順は naoshi の3章（`python3 build.py`・`python3 kakunin.py`・VER）。公開は koukai
