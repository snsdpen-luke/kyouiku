# kyouiku — 工業高校の教材

どれも**単一HTML・ビルド不要・依存なし・通信なし**。生徒はChromebookのブラウザで開く。

| 教材 | 何をするもの | 科目 |
|---|---|---|
| **ラダー工房** | 三菱系PLCのラダー図エディタ＋シミュレータ。仮想の機械（自動ドア・踏切・自動販売機・エレベーター）を動かす | 電子計測制御31 |
| **進路シミュレーション** | 「こんな暮らし」を選んで必要な手取りを逆算し、**ハローワークの求人票（見本）と同じ形**の求人票を欄ごとにタップして読み方を学ぶ | 進路学習（高2） |
| **翔陽ダービー** | 文化祭の来校者向け。校舎の中を馬で走るレースゲーム（スマホ縦持ち・60秒前後）。馬術部のある翔陽高校ならでは | 文化祭（配布） |
| **翔陽ミニマート** | 文化祭の来校者向け。My Mini Mart 風のタイクーン。売って稼いで、総合学科の **8コース**（機械・電気・建築・家庭科・農業園芸・農業食品製造・商業・普通科）を区画として建てていく（スマホ縦持ち・10〜20分・持ち帰って遊ぶ） | 文化祭（配布） |
| **こえサンプラー** | 16個のパッドを叩いて鳴らすサンプラー。音は16種類入っていて、どのパッドにも自分の声を録音して入れ替えられる | 音・情報（自由に使う） |
| **メッセージが届くまで** | トークアプリの送信ボタンの裏側（バイト→パケット→ヘッダ→ルーター→サーバー）をスローモーションで見る導入と、13ステージの自習教材・小テスト（TCP/IP） | コンピュータシステム技術（ネットワーク） |

## 別のパソコンで作業を始める

```bash
git clone https://github.com/snsdpen-luke/kyouiku.git
cd kyouiku
npm install jsdom          # 検証に使う。これだけ
node regression.js ラダー工房v2.html              # 85項目すべて合格すればOK
node regression-shinro.js 進路シミュレーション.html       # 121項目すべて合格すればOK
node regression-uma.js 馬レース.html                   # 61項目すべて合格すればOK
node regression-mart.js 翔陽ミニマート.html              # 90項目すべて合格すればOK
node regression-sampler.js サンプラー.html             # 61項目すべて合格すればOK
```

本体のHTMLをブラウザで直接開けば動く。サーバーは要らない。

## 直したときの手順

```bash
node regression.js ラダー工房v2.html              # 1. 検証（必ず通す）
node regression-shinro.js 進路シミュレーション.html       #    直したほうだけでよい
python3 build.py                                  # 2. 配布物を作り直す
git add -A && git commit -m "…"                   # 3. 記録
git push                                          # 4. 生徒の画面に反映される
```

画面右上の版表示（`版 2026-09-18d`）も更新すること。
本体の `const VER="…"` を書き換える。

## claude.ai の Artifact 版について

同じものを Artifact でも公開してある。`python3 build.py <出力先>` で
Artifact 用の断片を作り、それを publish する。

**注意**: Artifact は「リンクを知っている全員に公開」と「最新版を自動で配る」を
同時にできない。生徒に配る設定にすると版が固定され、更新のたびに手で
切り替えることになる。**配布は GitHub Pages を主にする。**

## こえサンプラーのメモ

- 入っている16音は**音のファイルではなく、プログラムで計算して作っている**（`SYNTH`）。だから通信なしで動く
- 録音した声は**その Chromebook のブラウザの中だけ**に保存（IndexedDB）。サーバーには送らない。別の端末には出てこない
- マイクは https でしか使えない。**ファイルを直接開くのではなく、上の GitHub Pages の URL で開く**
- 初めて「● ろくおん」を押すとマイクの許可を聞かれる。「許可」を押す。間違えて「ブロック」したら、アドレスバー右のマイクのマークから直す
- 実機（Chromebook）で未確認：タップしてから音が出るまでの遅れ、教室の雑音の中での録音の聞こえ方
