## デザイン規則（この2つを崩さない）

**色は4つだけ。色＝意味。**

| 色 | 意味 |
|---|---|
| 青緑 `#0d9488` | 電気が来ている（通電・入力ON） |
| 紫 `#6d28d9` | いまここ・押せる（選択・現在の課題・編集モード） |
| 桃 `#db2777` | まだ終わっていない（のこり・まちがい・警告） |
| 黄 `#facc15` | ランプが点いた（出力ONだけ） |

地は白 `#ffffff` と薄紫 `#f1edff`、線と字は `#1b1340`。それ以外を足さない。

**影＝押せるもの。平ら＝見るだけ。**
ボタン・スイッチ・現在のタブにだけ `4px 4px 0` の影を付ける。
静止したカードには付けない。説明しなくても生徒は影を探して指を置く。

**ラダー工房とは別物にする。** ベージュ地・橙のランプ・緑の通電・金属パネル・
丸ボタンは使わない（科目が違うものを同じ顔にすると生徒が区別しないため）。
