## 未決（ユーザー確認待ち）

**MIL記号 か JIS（IEC）記号 か。** いま描いてあるのは MIL記号。

| | MIL | JIS（IEC） |
|---|---|---|
| AND | 半円のD形 | 四角に `&` |
| OR | 盾形 | 四角に `≧1` |
| NOT | 三角＋小丸 | 四角に `1` ＋小丸 |
| XOR | 盾形＋弧 | 四角に `=1` |

教科書と検定の出題に合わせて決める。課題01〜04 では記号を出さない（電気が先、記号はあと）。

## デザイン規則（崩さない）

**色は4つだけ。色＝意味。**
青緑 `#0d9488`＝電気が来ている／紫 `#6d28d9`＝いまここ・押せる／
桃 `#db2777`＝まだ終わっていない／黄 `#facc15`＝ランプが点いた。
地は白と薄紫 `#f1edff`、線と字は `#1b1340`。それ以外を足さない。

**影＝押せるもの。平ら＝見るだけ。**

**ラダー工房とは別物にする。** ベージュ地・橙のランプ・緑の通電・金属パネル・
丸ボタンは使わない。

## 直しかた

```bash
# 1. _c.css（共通）と _b_*.part（各画面）を編集
# 2. 組み直す＋枠に収まっているか実測
cd 設計/つなぐ工房モック
for n in concept:Concept edit:Edit main:Main l05:Lesson05 half:HalfAdder hint:HintJudge; do
  cat _head.part _c.css _mid.part "_b_${n%%:*}.part" > "${n##*:}.dc.html"; done
cd 絵 && node check.mjs      # 全部 OK になること
node shot.mjs                # 画像を出し直す
```

**`check.mjs` は必ず通す。** body の余白を数え落として右端と下が切れる事故が実際に起きた。
`tsunagu-kobo-ui.html` は生成物。手で編集しない。
